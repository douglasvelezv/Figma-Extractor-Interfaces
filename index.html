Figma · Extractor de Interfaces

Extrae todos los frames de nivel superior de un archivo de Figma como PNG @2x, revísalos y descárgalos en un ZIP con una carpeta general. Tu token nunca sale de este navegador.

Lo generas en Figma → Settings → Security → Personal access tokens. Necesita el scope File content: Read-only. Se usa solo desde tu navegador; márcalo abajo si quieres recordarlo en este equipo.
Sirve cualquier enlace de /design/, /file/ o /proto/. Si es un archivo de la Comunidad, primero duplícalo a tus borradores (botón Open in Figma) para que tu token tenga acceso.
Opciones avanzadas
Si al generar el ZIP las imágenes fallan al descargarse, pega aquí un prefijo de proxy CORS de tu confianza (por ejemplo https://tu-proxy/?). Se antepone solo a las URLs de imagen de Figma.
